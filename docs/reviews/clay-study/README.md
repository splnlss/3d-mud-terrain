# Diagnostic clay studies — not an accepted look

These are actual Blender renders of a small 1.2 m calibration specimen, not
San Luis terrain. No polygon budget constrained them. Neither matches the
reference yet.

- `procedural-study.png`: continuous high-resolution geometry, coherent colour
  and roughness. Failed because nodules look like smooth dark spots and the
  clay is excessively soft.
- `scan-study.png`: removes the hemisphere nodules and tests registered colour,
  height bump and roughness from Rob Tuytel's
  [Brown Mud 03](https://polyhaven.com/a/brown_mud_03),
  [CC0](https://polyhaven.com/license). Finer detail responds more naturally,
  but it is too uniform and grey, lacks distinct fused crumb clusters and
  exposed ochre faces, and the ridge/groove patterns remain too regular.

The source photographs remain the style authority. A scan supplies microdetail;
it does not solve the sculptural forms or the material distribution. Next work
must establish those together before claiming a visual match or exporting the
regional terrain again.
